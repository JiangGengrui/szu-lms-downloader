# 畅课课件下载助手

> Chrome extension to download courseware from Shenzhen University LMS (lms.szu.edu.cn).

一个 Chrome / Edge 浏览器插件，用于**深圳大学畅课平台（lms.szu.edu.cn）**的课件下载。

解决痛点：老师上传课件时只开放了「阅读」权限、没有开放「下载」权限，导致无法离线学习、无法归档整理课件。本插件通过监听课件预览请求，提取真实下载链接，一键下载到本地。

## 功能特性

- **自动捕获**：进入课程 → 点击课件预览，插件自动监听到预览器请求，解码出真实下载地址（`media2.szu.edu.cn` 的带 token 链接）。
- **悬浮球（可拖动）**：页面右下角注入一个悬浮球，可长按拖动到任意位置、位置自动记忆；点击展开课件列表。
- **扩展弹窗**：点击浏览器工具栏的插件图标，弹出同样的课件列表，两种入口任选。
- **单个下载**：点击列表中的「下载」按钮，保存到浏览器默认下载目录，文件名自动还原为课件原名（含中文）。
- **全部下载**：点击「全部下载」一键发起列表中所有课件的下载任务，结果在浏览器底部下载栏查看。
- **自动去重**：同一课件重复预览不会重复出现，只保留最新链接。

## 界面设计

整体采用**淡蓝白**配色：浅色清新背景 + 蓝色强调（`#2563eb`），数字与标签使用等宽字体。插件图标为白底 + 淡蓝「打开的书本」，书脊向下延伸成箭头，寓意「书 = 课件、箭头 = 下载」。

## 安装步骤（以 Chrome 为例）

1. 打开浏览器地址栏，输入 `chrome://extensions` 并回车（Edge 是 `edge://extensions`）。
2. 打开右上角的 **「开发者模式」** 开关。
3. 点击左上角 **「加载已解压的扩展程序」**。
4. 选择本插件的文件夹（即包含 `manifest.json` 的 `szu-lms-downloader` 文件夹）。
5. 看到插件图标出现在工具栏即安装成功。建议点击工具栏的「拼图」图标，把本插件 **固定** 到工具栏，方便点击。

> 注意：加载后请保持 `manifest.json` 所在文件夹位置不变，不要移动或删除，否则插件会失效。

## 使用方法

1. 登录畅课平台，进入某个课程。
2. 打开课程的「课件」页面，点击任意课件进入预览。
3. 此时页面右下角悬浮球上会出现角标（数量），点击悬浮球展开列表。
4. 点击对应课件的「下载」按钮即可下载。

> 也可以点击浏览器工具栏的插件图标，在弹窗里看到同样的课件列表。

**批量下载建议**：先逐个点开需要下载的课件预览一遍（刷新链接），再点「全部下载」，避免个别链接过期导致失败。

## 工作原理

1. 课件预览是通过 `note-bene` 预览器加载的，预览器地址形如：
   `https://lms.szu.edu.cn/note-bene/pdf-viewer?file=<编码后的下载地址>&upload_id=...&course_id=...`
2. 插件后台脚本通过 `chrome.webRequest` 监听这些请求。
3. 从 `file` 参数解码出真实的下载地址：
   `https://media2.szu.edu.cn:443/download/file/<文件hash>?timestamp=...&token=...&name=<文件名>`
4. 下载时浏览器自动携带登录 Cookie，`token` 已内嵌在地址里，因此无需额外鉴权即可下载。

## 技术栈

- **Manifest V3**：Chrome / Edge 通用扩展规范。
- **`chrome.webRequest`**：监听课件预览器的网络请求。
- **`chrome.downloads`**：执行文件下载（自动携带登录 Cookie）。
- **`chrome.storage`**：跨页面存储捕获的课件列表与悬浮球位置。
- **原生 HTML / CSS / JavaScript**：无任何第三方框架，零依赖。

## 注意事项

- **链接时效**：下载地址里的 `token` / `timestamp` 带有效期，通常一段时间后（约 1 天内）会失效。若下载失败，回到课件页面**重新点击一次预览**刷新链接即可。
- **仅限个人学习使用**：请尊重版权与平台规定，下载的课件仅用于个人离线学习，勿用于传播或商业用途。
- **适用浏览器**：Chrome、Edge 等所有基于 Chromium 内核的浏览器（需支持 Manifest V3）。
- **仅对畅课平台生效**：插件只监听 `lms.szu.edu.cn` 域名，不会影响其他网站。

## 常见问题

**Q：下载失败，提示「失败」？**
多为链接过期，回到课件页重新点一次预览刷新链接后重试。

**Q：点了「全部下载」没反应？**
先到 `chrome://extensions` 点插件的「刷新」图标，再回到畅课页面按 F5 刷新；然后重新预览课件后再试。

**Q：更新了代码 / 样式，怎么生效？**
到 `chrome://extensions` 点插件「刷新」图标，并刷新畅课页面（F5）。

**Q：能下载视频吗？**
插件会捕获所有被预览器打开的课件（PDF、Office、视频等），能否下载取决于平台是否提供该文件的下载地址。
